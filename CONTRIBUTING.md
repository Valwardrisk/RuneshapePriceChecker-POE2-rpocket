## 🛠 Features

*   **Real-time Data:** Fetches pricing from verified sources every few minutes.
*   **Overlay Display:** Shows item prices in a small, non-intrusive window over your game.
*   **League Support:** Tracks specific items tied to current league mechanics.
*   **Performance:** Uses minimal RAM to ensure your game stays smooth.
*   **Search Integration:** Links directly to the poe2scout database for deeper item analysis.

## 📥 How to Download and Install

Follow these steps to set up the software on your Windows computer.

## ⚙️ How to Use the Tool

Once the installation finishes, you will see the RuneshapePriceChecker icon on your desktop.

1. Launch your game, Path of Exile 2, and set the display mode to "Windowed Fullscreen." This setting allows the overlay to appear on top of your game window.
2. Open the RuneshapePriceChecker application.
3. The tool initializes and connects to the internet to pull the latest item list.
4. Hover your mouse over any item inside your game inventory.
5. Press the default hotkey (Ctrl + D) to view the price information.

## 🔑 Troubleshooting Common Issues

If the overlay does not appear, verify the following details:

*   **Windowed Mode:** The application requires "Windowed Fullscreen" mode to draw the price window over your game. Exclusive fullscreen mode blocks external overlays.
*   **Permissions:** You may need to run the application as an administrator. Right-click the application icon and select "Run as administrator."
*   **Network Access:** Ensure your firewall allows the application to connect to the internet. The tool needs access to fetch live prices from the server.
*   **Hotkey Conflicts:** If another program uses the same hotkey, open the "Settings" menu inside the tool to assign a different key combination.

## 📝 Configuration Settings

You can customize the behavior of the price checker within the "Settings" tab. 

*   **Display Theme:** Choose between a dark or light background for the price window.
*   **Refresh Rate:** Adjust how often the tool asks the server for new price data. The default is 5 minutes.
*   **Currency Format:** Select your preferred currency for display, such as Chaos Orbs or Divine Orbs.
*   **Transparency:** Modify the opacity of the overlay to keep your vision of the game world clear.

## 🛡 System Requirements

*   **Operating System:** Windows 10 or Windows 11.
*   **Memory:** At least 4GB of RAM assigned to your computer.
*   **Network:** A stable internet connection for real-time price updates.
*   **Resolution:** The overlay scales automatically for 1080p and 1440p monitors.
